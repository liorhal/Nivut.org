# ניווט ישראל – אתר מעטפת ל-nivut.org.il

אתר סטטי, נגיש ומודרני שמציג את המידע של [איגוד הניווט הישראלי](https://www.nivut.org.il/) בצורה נוחה:

- **ניווטים קרובים** – ספירה לאחור לאירוע הבא, כרטיסי אירועים לפי חודש, חיפוש, סינון לפי אזור ולפי סוג אירוע (ליגה, אליפות, ספרינט, לילה, אופני ניווט, רוגיין, בתי ספר, אימון), התראה על סגירת הרשמה, הוספה ליומן (ICS) וניווט ב-Waze.
- **תוכנית שנתית** – תצוגת עונה (ספטמבר–אוגוסט) ותצוגת לוח חודשי, עם מקרא צבעים והורדת כל העונה ליומן.
- **פורום** – נושאים אחרונים לפי קטגוריה, עם קישור לאירוע הרלוונטי ולפורום המלא.

## נגישות
RTL מלא, קישור "דלג לתוכן", ניווט מלא במקלדת, טבעת פוקוס בולטת, הגדלה והקטנה של הגופן, מצב ניגודיות גבוהה, מצב כהה (כולל לפי הגדרות המערכת), כיבוד `prefers-reduced-motion`, חלוני `dialog` נגישים וטבלת לוח עם כותרות.

## הרצה
אין שלב build. אפשר להריץ כל שרת סטטי:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

מתאים להעלאה ל-GitHub Pages, ל-Netlify וכו'.

## נתונים
כל התוכן נטען מקבצי JSON בתיקייה `data/`:

| קובץ | תוכן |
|---|---|
| `data/events.json` | סוגי אירועים (שם + צבע) ורשימת אירועים (`date`, `time`, `title`, `type`, `location`, `region`, `club`, `courses`, `registrationDeadline`, `lat`/`lng`, `url`, `description`) |
| `data/forum.json` | קטגוריות ונושאים בפורום (`title`, `author`, `replies`, `lastActivity`, `url`, `eventId`) |
| `data/config.json` | קישורים לאתר המקורי, ו-`sampleData` שמציג באנר "נתוני דוגמה" |

> ⚠️ **הנתונים הנוכחיים הם נתוני דוגמה.** יש להחליף אותם בנתונים מתוך
> [לוח האירועים הרשמי](https://nivut.org.il/calendar.aspx) ולהגדיר `"sampleData": false`.
> כתובת הפורום ב-`config.json` (`links.forum`) מצביעה כרגע לדף הבית ויש לעדכן אותה.
