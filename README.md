# ניווט ישראל – מעטפת חיה ל-nivut.org.il

אתר נגיש ומודרני שמציג **בזמן אמת** את המידע מאתר [איגוד הניווט הישראלי](https://nivut.org.il/). אין באתר נתונים שמורים: כל בקשה נקראת מאתר האיגוד.

- **ניווטים קרובים** – ספירה לאחור לאירוע הבא, כרטיסי אירועים לפי חודש, חיפוש, סינון לפי סוג ולפי מועדון, הוספה ליומן (ICS), Waze וקישור לדף האירוע באתר האיגוד.
- **תוכנית שנתית** – תצוגת עונה (ספטמבר–אוגוסט) ולוח חודשי, עם מקרא צבעים והורדת כל העונה ליומן.
- **פורום** – הנושאים האחרונים מהפורום של האיגוד, עם חיפוש וקישור אוטומטי לאירוע שהנושא עוסק בו.

## איך זה עובד

```
דפדפן ──► server.js ──► nivut.org.il (calendar.aspx, דף הבית, הפורום)
             │  lib/nivut.js: מוריד, מפענח קידוד (UTF-8 / windows-1255), מחלץ אירועים ונושאים
             └► /api/events, /api/forum, /api/links  (JSON, מטמון של 10 דקות)
```

דפדפן לא יכול לקרוא ישירות מ-nivut.org.il מדומיין אחר (CORS), לכן יש שרת Node קטן שמשמש כמתווך.
אם אתר האיגוד לא זמין, מוצג המידע האחרון שנקרא, עם הודעה על כך.

**המפענח סובלני:** הוא מחפש שורות טבלה שיש בהן תאריך וממפה עמודות לפי הכותרות (תאריך, שם, מקום, מארגן, סוג).
אם לא נמצאה טבלה, הוא מנסה רשימות. סוג האירוע (ליגה, אליפות, לילה וכו') נקבע לפי מילות מפתח.

## הרצה

נדרש Node 18 ומעלה, ללא תלויות.

```bash
npm start            # http://localhost:8080
npm run inspect      # בדיקה מול האתר החי: מה המפענח מוצא בכל עמוד
npm test             # בדיקות יחידה למפענח
```

משתני סביבה (לא חובה):

| משתנה | ברירת מחדל | |
|---|---|---|
| `PORT` | `8080` | |
| `NIVUT_BASE` | `https://nivut.org.il/` | כתובת המקור |
| `NIVUT_FORUM_URL` | מזוהה אוטומטית מקישור "פורום" בדף הבית | |
| `CACHE_SECONDS` | `600` | משך המטמון |

## אחסון

כל שירות שמריץ Node מתאים (Render, Railway, Fly.io, VPS וכו'): פקודת ההפעלה היא `npm start`.
אחסון סטטי בלבד (GitHub Pages) **לא** מספיק, כי צריך את השרת המתווך.

## לפני עלייה לאוויר

המפענח נבדק מול HTML לדוגמה (`test/fixtures`) ולא מול האתר האמיתי, כי סביבת הפיתוח לא הורשתה לגשת ל-nivut.org.il.
יש להריץ `npm run inspect` ממחשב עם גישה לאתר ולוודא שהאירועים והפורום נקראים נכון.
