# ניווט ישראל – מעטפת חיה ל-nivut.org.il

אתר נגיש ומודרני שמציג **בזמן אמת** את המידע מאתר [איגוד הניווט הישראלי](https://nivut.org.il/). אין באתר נתונים שמורים: הכול נקרא מאתר האיגוד.

- **ניווטים קרובים** – ספירה לאחור לאירוע הבא; כרטיסי אירועים עם תמונה, סוג ניווט (רגלי / רכוב / עממי) ואופי האירוע (אליפות, ליגה, ספרינט, אימון…); שעות זינוק, מקום, מועדון וספירה לאחור עד סגירת ההרשמה המוקדמת; הוספה ליומן, Waze לנקודת הכינוס והרשמה באתר האיגוד.
- **עמוד תחרות** (`#event/<id>`, קישור שאפשר לשתף):
  - **מבט ראשון:** מתי, איפה, כמה ומצב ההרשמה, עם ספירה לאחור לסגירת ההרשמה המוקדמת וכפתור הרשמה בולט.
  - **ציר הזמן של יום התחרות:** חלון הזינוקים, שעת הגג ו"עכשיו", עם הסבר של המונחים למתחילים.
  - **בחירת מסלול:** פסי אורך, רמת קושי וסימון "מתאים למתחילים".
  - **איך מגיעים:** מפת נקודת הכינוס, Waze והוראות הגעה.
  - **מידע נוסף:** מפת הניווט, המארגנים (עם טלפון לחיץ), קבצים ושרשורי פורום קשורים.
  - **במובייל:** סרגל פעולות קבוע להרשמה, Waze, יומן ושיתוף.
- **תוכנית שנתית** – תצוגת עונה וחודש. כוללת את האירועים המפורסמים ואת השטחים הסגורים (תחרויות עתידיות שפרטיהן טרם פורסמו).
- **פורום** – נושאי השבוע האחרון עם ההודעה המלאה והתגובות, חיפוש, הכרזות ונעוצים, וקישור לאירוע שהנושא עוסק בו.
- **חדשות האיגוד**.
- **סינון קבוע לסוגי ניווט** – כפתורי רגלי, רכוב ועממי בראש העמוד. הבחירה נשמרת בעוגייה `nivut_disc` לשנה, וחלה על הניווטים הקרובים, הרשימה והתוכנית השנתית.
- **האנשים שלי** – רשימת נווטים שמעניינים אתכם, שנשמרת רק בדפדפן. בכל אירוע מוצג מי מהם רשום, עם קטגוריה, מסלול ושעת זינוק אם הם מופיעים ברשימה. ההתאמה בין השמות נעשית בדפדפן, כך שהשרת לא יודע אחרי מי אתם עוקבים.

## מקורות המידע

| עמוד באתר האיגוד | מה נקרא ממנו | מצב |
|---|---|---|
| דף הבית | אירועים מפורסמים, שטחים סגורים, חדשות | מפענח לפי המבנה האמיתי ✅ |
| דף אירוע (`/{id}/Info`) | כל פרטי האירוע | מפענח לפי המבנה האמיתי ✅ |
| פורום (`/forums/`) | נושאים, הודעות ותגובות | מפענח לפי המבנה האמיתי ✅ |
| `calendar.aspx` | לוח האירועים המלא | מפענח כללי, **טרם נבדק מול העמוד האמיתי** ⚠️ |
| רשימת משתתפים (כפתור בדף האירוע) | שמות, מועדון, קטגוריה, מסלול, שעת זינוק | הגעה דרך postback ופענוח לפי כותרות הטבלה, **טרם נבדק מול העמוד האמיתי** ⚠️ |

```
דפדפן ──► api/*.js (Vercel) ──► nivut.org.il
             │  lib/nivut.js: הורדה, פענוח קידוד (UTF-8 / windows-1255), חילוץ ומיזוג
             └► /api/events  /api/event?id=  /api/participants?id=  /api/forum  /api/news  /api/links   (מטמון 10 דק')
```

דפדפן לא יכול לקרוא ישירות מ-nivut.org.il מדומיין אחר (CORS), לכן יש שרת Node קטן שמשמש כמתווך.
אם אתר האיגוד לא זמין, מוצג המידע האחרון שנקרא, עם הודעה על כך.
`/api/event` מקבל רק מזהה מספרי של אירוע, כך שהשרת אינו פרוקסי פתוח.

## הרצה

נדרש Node 18 ומעלה, ללא תלויות.

```bash
npm start            # http://localhost:8080
npm run inspect      # בדיקה מול האתר החי: מה נקרא מכל עמוד
npm test             # בדיקות יחידה למפענחים
```

| משתנה סביבה | ברירת מחדל |
|---|---|
| `PORT` | `8080` |
| `NIVUT_BASE` | `https://nivut.org.il/` |
| `NIVUT_FORUM_URL` | `{NIVUT_BASE}forums/` |
| `CACHE_SECONDS` | `600` |

## פריסה ל-Vercel

הפרויקט מוכן ל-Vercel, ללא שלב build:

- `public/` – האתר (HTML, CSS ו-JS).
- `api/*.js` – פונקציות serverless: `/api/events`, `/api/event`, `/api/forum`, `/api/news`, `/api/links`.
- `vercel.json` – תיקיית הפלט `public` וזמן ריצה מרבי של 30 שניות לפונקציה.
- תגובות ה-API נשמרות במטמון של ה-CDN ל-10 דקות (`s-maxage=600`), ובמשך יום מוגשת הגרסה הקודמת בזמן הרענון. כך אתר האיגוד לא מקבל עומס.

**חיבור חד-פעמי:** ב-[vercel.com/new](https://vercel.com/new) מייבאים את המאגר `liorhal/nivut.org` מ-GitHub ולוחצים Deploy, בלי לשנות הגדרות.
מכאן כל push לענף הראשי מתפרסם אוטומטית, וכל ענף אחר מקבל כתובת Preview.

`npm start` מריץ מקומית את אותן פונקציות בדיוק.
