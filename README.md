# ניווט ישראל – מעטפת חיה ל-nivut.org.il

אתר נגיש ומודרני שמציג **בזמן אמת** את המידע מאתר [איגוד הניווט הישראלי](https://nivut.org.il/). אין באתר נתונים שמורים: הכול נקרא מאתר האיגוד.

- **ניווטים קרובים** – ספירה לאחור לאירוע הבא; כרטיסי אירועים עם תמונה, סוג ניווט (רגלי / רכוב / עממי) ואופי האירוע (אליפות, ליגה, ספרינט, אימון…); דיאגרמה מוקטנת של יום התחרות (זינוק ראשון, זינוק אחרון ושעת גג), מקום, מועדון וספירה לאחור עד סגירת ההרשמה המוקדמת; כפתור Waze לנקודת הכינוס ליד המקום, והרשמה באתר האיגוד. ב"עוד ניווטים" אותם כרטיסים כמו בארבעת הקרובים. מוצגים החודשיים הקרובים, וכל לחיצה על "הצג עוד" מוסיפה חודשיים. בחיפוש מוצגות כל התוצאות. בניווטים הקרובים מוצגים רק אירועים שיש להם עמוד הרשמה באתר האיגוד. אירוע מוסתר כשב"מידע נוסף" שלו כתוב "אין הרשמה באתר", או כשכתוב "אירוע סגור" במידע הנוסף או בשורה שמתחת לשם האירוע (אירוע סגור מוסתר גם בתוכנית השנתית). אירועים שמגיעים מלוח האירועים נבדקים בדפדפן רק כשהם נכנסים לחודשים המוצגים – החודשיים הראשונים, ועוד חודשיים בכל "הצג עוד" – והתשובה נשמרת בדפדפן ל-12 שעות. שטחים סגורים ואירועים שמופיעים רק בלוח השנה מוצגים רק בתוכנית השנתית. בכל כרטיס יש כפתור "ⓘ מידע נוסף" שפותח את עמוד התחרות בחלק "מידע נוסף" (בראש העמוד).
- **כרטיס ניווט ("כרטיס כניסה")** – עמודת תאריך בצבע סוג הניווט (ירוק רגלי, כחול רכוב), עם הכוכב של האנשים שלי, וקו תלישה מקווקו עם חריצים. בגוף הכרטיס: ליגה / המועדון שלי, המועדון המארגן משמאל (והלוגו שלו שקוף ברקע), שם האירוע, מרחק ו־Waze, דיאגרמת הזינוקים, והרשמה קומפקטית בשורה אחת. במובייל ארבעת הקרובים בלי דיאגרמה, כדי להיכנס במסך אחד.
- **עמוד תחרות** (`#event/<id>`, קישור שאפשר לשתף):
  - **מבט ראשון:** שלוש קוביות – מתי (תאריך, בעוד כמה ימים ודיאגרמת היום), איפה (ומרחק), והרשמה.
  - **הרשמה:** למעלה אזור קטן – ספירה לאחור לסגירת ההרשמה המוקדמת, כפתור הרשמה ו"ההרשמות שלי" (מי מהאנשים שלי רשום ומתי הוא מזנק). למטה אזור "הרשמה" עם כל הפרטים – מועד הסגירה, מחירים, הרשמה במקום, מספר המשתתפים והקישור לרשימה, והאנשים שלי עם קטגוריה ומסלול.
  - **ציר הזמן של יום התחרות:** חלון הזינוקים, שעת הגג ו"עכשיו", עם הסבר של המונחים למתחילים.
  - **בחירת מסלול:** פסי אורך, רמת קושי וסימון "מתאים למתחילים".
  - **איך מגיעים:** מפת נקודת הכינוס, Waze והוראות הגעה.
  - **מידע נוסף:** מפת הניווט, המארגנים (עם טלפון לחיץ), קבצים ושרשורי פורום קשורים.
  - **במובייל:** סרגל פעולות קבוע להרשמה, Waze ושיתוף.
- **תוכנית שנתית** – תצוגת עונה וחודש. כוללת את האירועים המפורסמים ואת השטחים הסגורים (תחרויות עתידיות שפרטיהן טרם פורסמו).
- **פורום** – נושאי השבוע האחרון עם ההודעה המלאה והתגובות, חיפוש, הכרזות ונעוצים, וקישור לאירוע שהנושא עוסק בו.
- **עזרה (כפתור ?)** – כרטיס ניווט לדוגמה עם שבעה הסברים קצרים. במסך רחב חיצים מכל נתון להסבר שלו, ובמובייל מספרים על הכרטיס ומקרא מתחתיו.
- **נגישות ותצוגה** – כפתור אחד בכותרת שנפתח לגודל גופן, ניגודיות גבוהה ומצב כהה.
- **קבצים ונספחים** – בעמוד התחרות, מתוך תיבת "קבצים ונספחים" באתר האיגוד. כל קובץ מסווג: דבר המתכנן, זמני זינוק, תוצאות (גם LIVE RESULTS, ודף התוצאות של האיגוד כשהוא פתוח) וניתוח תוצאות (Livelox, LapCombat, SplitsBrowser, WinSplits, RouteGadget). לפני האירוע מודגשים דבר המתכנן וזמני הזינוק, ומיום האירוע – התוצאות והניתוח.
- **תוצאות אחרונות** – בעמוד הראשי שלושת האירועים האחרונים (כולל היום), עם קישורי התוצאות וניתוח התוצאות בלבד.
- **חדשות האיגוד**.
- **לוגואים של מועדונים** – ליד המארגן בכרטיסים ובעמוד התחרות, ליד כל כותב בפורום, וליד משתתפים. הלוגו נלקח מעמוד המועדון (`/Club/{מספר}`, למשל `images/clubs/modiin.jpg`) ונשמר במטמון ליום. בגיבוי: הלוגו שבדף האירוע, טבלת לוגואים ידועים, `club-logos/club{מספר}.png`, ובסוף האות הראשונה של שם המועדון.
- **המועדון שלי** – נבחר בחלון "ההגדרות שלי" ונשמר בעוגייה `nivut_club`. אירועי המועדון מסומנים "⚑ המועדון שלי", ובחיפוש יש "רק אירועים של המועדון שלי".
- **מרחק מהמיקום שלי** – (נקודת צבע: ירוק קרוב, צהוב-כתום באמצע, אדום מ-150 ק"מ ומעלה) בחלון "ההגדרות שלי" בוחרים יישוב או "לפי המיקום הנוכחי". המיקום נשמר רק בדפדפן (localStorage), מעוגל לכקילומטר, ולא נשלח לשרת. המרחק בקו אווירי מוצג בסוגריים אחרי שם המקום, בכרטיסים ובקוביית "איפה" בעמוד התחרות. כשלא נקבע מיקום, קוביית "איפה" מציעה לקבוע אותו. ובחיפוש אפשר לסנן "עד X ק"מ". המרחק ידוע רק לאירועים שבדף שלהם יש קואורדינטות.
- **הדגשת אירועי ליגה** – תגית "🏆 ליגה" ופס זהב בכרטיסים, בעמוד התחרות ובתוכנית השנתית.
- **סינון קבוע לסוגי ניווט** – כפתורי רגלי, רכוב ועממי בראש העמוד. הבחירה נשמרת בעוגייה `nivut_disc` לשנה, וחלה על הניווטים הקרובים, הרשימה והתוכנית השנתית.
- **סינון מהיר "הניווטים שלי"** – כפתור כוכב ליד סוגי הניווט (מופיע כשיש אנשים ברשימה). בלחיצה נבדקות רשימות המשתתפים של כל הניווטים הקרובים.
- **האנשים שלי** – רשימת נווטים שמעניינים אתכם, שנשמרת רק בדפדפן. בעמוד התחרות מוצג מי מהם רשום, עם קטגוריה, מסלול ושעת זינוק. ההתאמה בין השמות נעשית בדפדפן, כך שהשרת לא יודע אחרי מי אתם עוקבים. בכרטיסים: כוכב זהב עם מספר הרשומים, וטולטיפ עם השמות ושעות הזינוק.

## מקורות המידע

| עמוד באתר האיגוד | מה נקרא ממנו | מצב |
|---|---|---|
| דף הבית | אירועים מפורסמים, שטחים סגורים, חדשות | מפענח לפי המבנה האמיתי ✅ |
| דף אירוע (`/{id}/Info`) | כל פרטי האירוע | מפענח לפי המבנה האמיתי ✅ |
| פורום (`/forums/`) | נושאים, הודעות ותגובות | מפענח לפי המבנה האמיתי ✅ |
| `calendar.aspx` | לוח האירועים המלא | מפענח כללי, **טרם נבדק מול העמוד האמיתי** ⚠️ |
| רשימת משתתפים (`/{id}/Start`, ובגיבוי הכפתור בדף האירוע) | שמות, מועדון, קטגוריה (מעמודה או מכותרת קבוצה), מסלול, שעת זינוק | פענוח לפי כותרות הטבלה, **טרם נבדק מול העמוד האמיתי** ⚠️ |

```
דפדפן ──► api/*.js (Vercel) ──► nivut.org.il
             │  lib/nivut.js: הורדה, פענוח קידוד (UTF-8 / windows-1255), חילוץ ומיזוג
             └► /api/events  /api/event?id=  /api/participants?id=  /api/forum  /api/news  /api/links   (מטמון 10 דק')
```

דפדפן לא יכול לקרוא ישירות מ-nivut.org.il מדומיין אחר (CORS), לכן יש שרת Node קטן שמשמש כמתווך.
אם אתר האיגוד לא זמין, מוצג המידע האחרון שנקרא, עם הודעה על כך.
`/api/event` מקבל רק מזהה מספרי של אירוע, כך שהשרת אינו פרוקסי פתוח.

## הרצה

נדרש Node 18 ומעלה, ללא תלויות.

```bash
npm start            # http://localhost:8080
npm run inspect      # בדיקה מול האתר החי: מה נקרא מכל עמוד
npm test             # בדיקות יחידה למפענחים
```

| משתנה סביבה | ברירת מחדל |
|---|---|
| `PORT` | `8080` |
| `NIVUT_BASE` | `https://nivut.org.il/` |
| `NIVUT_FORUM_URL` | `{NIVUT_BASE}forums/` |
| `CACHE_SECONDS` | `600` |

## פריסה ל-Vercel

הפרויקט מוכן ל-Vercel, ללא שלב build:

- `public/` – האתר (HTML, CSS ו-JS).
- `api/*.js` – פונקציות serverless: `/api/events`, `/api/event`, `/api/forum`, `/api/news`, `/api/links`.
- `vercel.json` – תיקיית הפלט `public` וזמן ריצה מרבי של 30 שניות לפונקציה.
- תגובות ה-API נשמרות במטמון של ה-CDN ל-10 דקות (`s-maxage=600`), ובמשך יום מוגשת הגרסה הקודמת בזמן הרענון. כך אתר האיגוד לא מקבל עומס.

**חיבור חד-פעמי:** ב-[vercel.com/new](https://vercel.com/new) מייבאים את המאגר `liorhal/nivut.org` מ-GitHub ולוחצים Deploy, בלי לשנות הגדרות.
מכאן כל push לענף הראשי מתפרסם אוטומטית, וכל ענף אחר מקבל כתובת Preview.

`npm start` מריץ מקומית את אותן פונקציות בדיוק.
